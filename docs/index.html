How it works

A watermark cannot be "undone" unless the exact logo is already known. What can be done is to remove the area you mark and fill it back in from the pixels around it.

  • Images — inpainting with the MI-GAN model through onnxruntime-web. Around 1.6 seconds per image.
  • Video — ffmpeg's own delogo filter, running as WebAssembly. Every frame is interpolated from the edges of the box you mark. The original audio is copied across untouched, never re-encoded.

For a small semi-transparent watermark that stays in one place — exactly like the Veo/Gemini mark — delogo is enough and very fast. When there is texture or detail behind the watermark, use the desktop version with the migan engine: the difference is clearly visible.

Limits

  • Video is processed on a single thread. GitHub Pages cannot send the COOP/COEP headers that multi-threaded ffmpeg needs, so long clips take a while. Use the desktop version for those.
  • A watermark that changes position is only handled by the desktop version, which tracks it frame by frame.
  • Only the visible watermark is removed. Invisible ones such as SynthID are untouched.

Desktop version

Faster and more capable: the LaMa engine for the highest quality, MI-GAN on the GPU for video (a 10-second clip finishes in 29 seconds), and tracking for moving watermarks. It lives at github.com/Skyrooth/WatermarkRemover.
